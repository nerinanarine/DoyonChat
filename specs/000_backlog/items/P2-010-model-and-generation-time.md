# P2-010: 生成メッセージへのモデル名・生成時間表示

## 概要

生成されたassistantメッセージに、実際に利用したモデル名と生成時間を表示する。

モデルを会話途中で切り替えた場合でも、各メッセージにはそのメッセージの生成に使用したモデルを表示する。生成時間は、質問の送信から最初の回答本文が画面に表示されるまでの時間を基本とする。正確な計測地点と表示単位は、実装時のSpec/Planで確定する。

## 受け入れ条件

1. 生成済みassistantメッセージに、利用したモデルのユーザー向け表示名が表示される
2. 表示されるモデル名は、現在選択されているモデルではなく、そのメッセージ生成時に利用したモデルである
3. 質問送信から最初の回答本文が表示されるまでの生成時間が、メッセージ単位で表示される
4. 生成時間はユーザーが読みやすい単位（例: `1.2秒`、`850ms`）で表示される
5. ストリーミング応答が完了した後も、モデル名と生成時間が表示される
6. 会話を再読み込みした後も、保存済みメッセージのモデル名と生成時間が復元される
7. 既存メッセージにメタデータがない場合、メッセージ本文の表示は壊れず、メタデータだけを非表示または利用不能として扱う
8. Reasoning表示、Markdown表示、ストリーミング表示など既存のメッセージ表示を壊さない

## エッジケース

- **モデル名がモデル一覧に存在しない**: 保存されたモデルIDをフォールバック表示する
- **生成時間が計測できない**: 本文表示を優先し、生成時間を表示しない
- **Reasoningだけが先に届く**: 「回答本文」の表示時間として扱う計測タイミングを明確化する
- **ストリーミングが中断された**: 部分保存の扱いはP1-003に従い、本項目では新たな中間保存を追加しない
- **過去データ**: `model`や`generationTimeMs`がない既存Messageを後方互換で表示する

## 技術的実装方針（案）

Messageに生成時メタデータを任意フィールドとして追加する。

```json
{
  "id": "uuid",
  "conversationId": "uuid",
  "role": "assistant",
  "content": "回答本文",
  "reasoning": "思考プロセス全文",
  "model": "kimi-k2.6",
  "generationTimeMs": 1230,
  "createdAt": "..."
}
```

- モデルは生成時に利用したモデルIDを保存し、Frontendで表示名へ変換する
- 生成時間は「質問送信」から「最初の回答本文の表示」までを基本とする
- Functionsで計測した上流TTFTと、Frontendで計測した送信から表示までの時間のどちらを採用するかは、Spec/Planで確定する
- DBの既存データは移行せず、任意フィールドとして後方互換性を維持する

## Out of Scope

- モデルの切り替えUI自体の変更
- トークン数、料金、CPU時間などの詳細な利用量表示
- 過去Messageへのモデル名・生成時間の一括推定・移行
- ストリーミング中断時の部分保存（P1-003）
