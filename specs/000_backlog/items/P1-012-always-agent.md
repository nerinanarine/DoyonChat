# P1-012: 常時Agentモード・旧一問一答の廃止

## 概要

チャットを常に Agentモードで起動するようにし、旧来の一問一答形式（モデルを直接選択して OpenCode Go に投げる通常チャット）の機能を廃止する。

## 背景

- Agentモード（P3-010）と通常チャットの二系統が併存し、保守・UXが分散している
- 今後はエージェントに集約したい

## 方針（確定事項）

- **方向**: Agentモードに一本化（デフォルト化ではなく、通常チャットの完全削除）
- **廃止範囲**: 通常チャットのUI・API・モデル選択導線を削除する
- **残すもの**: Agentモードの起動・承認フロー・ファイル/検索等のエージェント拡張（P3-014/P3-015/P3-016）

## 検討項目

- [ ] 廃止対象の棚卸し（通常チャットUI・`chat.ts`/`conversations.ts`等のFunctions・モデル選択・設定の既定モデル）
- [ ] Agentモード未対応機能の救済（通常チャットでできてAgentでできないことの洗い出し）
- [ ] 既存会話データの扱い（通常チャット履歴の閲覧可否・移行要否）
- [ ] P2-008（ユーザー設定の既定モデル）・P2-010（モデル名表示）等の関連項目への影響
- [ ] 削除順序（フロント先行かバックエンド先行か・段階削除か一括削除か）

## 受け入れ条件

（詳細は [spec](../../P1-012/spec.md)・[plan](../../P1-012/plan.md) を参照）

1. チャット開始時に常にAgentモードが起動する
2. 旧一問一答のUI・API導線が削除され、ユーザーが通常チャットに戻れない
3. 既存会話の扱い（閲覧可否・移行）が確定し、実装と一致している
4. Agentモードの承認フローに回帰がない
5. 削除したコード・設定・ドキュメントに残骸（到達不能UI・未使用API・記述）がない
