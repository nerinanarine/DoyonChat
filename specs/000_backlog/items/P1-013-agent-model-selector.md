# P1-013: Agent実行モデル選択ドロップダウン（Pi model連動）

## 概要

チャット画面にモデル選択ドロップダウンを残し（P1-012で削除した通常チャット用とは別物）、Agent実行モデル（Piのmodel）の選択に紐づける。

## 背景

- P1-012 で通常チャット用のモデル選択を削除したが、Agentが使うモデルの選択UIは必要との方針変更
- 既存のユーザー設定には `agentModel`／`agentSubagentModel` がある

## 方針（確定事項）

- **対象**: Agent実行モデルの選択UI（通常チャットの復活ではない）
- **連動**: Piのmodel（`agentModel` 系設定）と紐づける

## 検討項目（spec起草前に確定が必要）

- [ ] 選択肢の範囲：正規30モデル全体か、Agent用に絞った一覧か
- [ ] 紐付け先：ユーザー設定の `agentModel` に連動か、会話ごとに保持か
- [ ] 配置：以前のヘッダー位置に戻すか、別位置か
- [ ] `agentSubagentModel` の扱い（選択対象に含めるか）
- [ ] P2-019（カタログ30件）との連携（選択肢の供給源）

## 受け入れ条件

（詳細は [spec](../../P1-013/spec.md)・[plan](../../P1-013/plan.md) を参照）

1. チャット画面からAgent実行モデルを選択できる
2. 選択が Pi の実行モデルに反映される
3. 通常チャットのUI・APIが復活していない（P1-012の削除範囲を維持）
4. 既存の承認フロー・起動中表示（P2-018）に回帰がない

## 関連ファイル

- `frontend/src/`（選択UI。P1-012で削除した配置の再検討）
- `functions/src/`（ユーザー設定・Agent実行経路）
- `specs/P1-012/`（削除範囲との境界確認）

## 依存関係

- **ブロックする:** なし
- **ブロックされる:** P1-012（削除範囲との境界確定）、P2-019（選択肢の供給源）
