# P2-020: ユーザー別AGENTS.md編集UI

## 概要

ユーザー別の AGENTS.md をチャット画面のUIから参照・編集・保存できるようにする。AGENTS.md の参照・編集・保存はUIからのみ行わせる。

## 背景

- エージェントの振る舞い指示（AGENTS.md）をユーザーごとにカスタマイズしたい
- 直接ファイル操作ではなくUI経由に限定することで、安全な変更に留める

## 方針（確定事項）

- **対象**: ユーザー別 AGENTS.md
- **保存先**: Azure Files共有（`artifacts/{userId}/config/AGENTS.md`）。設定ファイルは共有上に置き、UIはそれをロードして表示・保存する（2026-10-04確定）
- **経路限定**: 参照・編集・保存はUIからのみ（直接のファイル操作手段を提供しない）
- **環境**: dev先行

## 検討項目（spec起草前に確定が必要）

- [ ] AGENTS.md の実体と保存先（既存のユーザー設定領域か、P3-016のFiles共有か、新規領域か）
- [x] 保存先は Azure Files共有に確定（2026-10-04）。gatewayは自マウント経由で読み、プロンプト毎にuserConfigDirへ再配置する
- [ ] gateway（pi）の読み込み経路との接続（保存後にエージェントへ反映される仕組み）
- [ ] 同時編集・バリデーション（空・巨大入力等の扱い）
- [ ] 変更履歴の要否（版管理するか）
- [ ] P3-016（ユーザー分離・所有者検証）との連携

## 受け入れ条件

（詳細は [spec](../../P2-020/spec.md)・[plan](../../P2-020/plan.md) を参照。保存先はAzure Files共有に確定済み）

1. チャット画面から自分の AGENTS.md を参照できる
2. チャット画面から編集・保存できる
3. 他ユーザーの AGENTS.md は参照・編集できない
4. 保存内容がエージェントの動作に反映される
5. UI以外の書込み経路が存在しない（参照は認証付きAPI限定。エージェント自身による自己文書への書込みは所有者同一の例外とする）
6. 既存の承認フロー・通常チャットに回帰がない
