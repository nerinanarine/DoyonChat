# P3-010: AIのエージェント化

## 概要

AIを単なるチャット応答者から、ツールを使いこなし自律的にタスクを遂行できるエージェントへ拡張する。Function Calling や外部API連携、マルチステップ推論などを検討・導入する。

## 背景

- 現状のチャットは「質問→回答」の1ターン形式が基本
- エージェント化により、ユーザーはより複雑なタスクを自然言語で委任できる
- 具体的なスコープは要検討（検索、計算、ファイル操作、外部API呼び出しなど）

## 検討項目

- [ ] Function Calling / Tools 対応モデルの選定と実装
- [ ] エージェントが使用可能なツールの定義（社内API、検索、計算など）
- [ ] マルチステップ推論のUI表現（進捗表示、思考プロセスの可視化）
- [ ] セキュリティ・権限管理（ツール実行前のユーザー確認が必要か）
- [ ] エラーハンドリング（ツール実行失敗時のフォールバック動作）

## 受け入れ条件

1. AIが特定のツールを必要と判断した場合、ツールを呼び出して結果を回答に反映できる
2. ツール実行中はユーザーに進捗が表示される
3. ツール実行前にユーザー確認が必要な場合は、明示的な承認フローがある
4. ツール呼び出し失敗時は、エラーを適切に処理してユーザーに通知する

## 関連ファイル

- `backend/src/services/chat.ts`（ツール呼び出しロジック追加）
- `frontend/src/components/ChatMessage.tsx`（ツール実行結果の表示）
- `frontend/src/components/ToolCallConfirmation.tsx`（新規：ツール承認UI）
