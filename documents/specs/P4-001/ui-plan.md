# P4-001: UIレスポンシブ対応計画

本計画は `ui-spec.md` に定めるUI改修本体の手順。対応backlog: `documents/specs/000_backlog/items/P4-001-ui-refactoring.md`。前段のローカルUI確認環境整備 (`plan.md`) とは別に実施し、既存の機能・デザイン意図を維持してレスポンシブ対応する。**着手ゲート:** UI改修方針のヒアリングが確定した後に着手し、未確定の間は実施しない。

## Phase 1: レイアウト

- [ ] アプリの外枠を利用可能なビューポート高に追従させ、モバイルの表示領域変化に対応する (`100dvh`、safe-area)。
- [ ] Tailwind既定の `sm` / `md` / `lg` を基準に、モバイルとデスクトップのレイアウトを整える。
- [ ] デスクトップでチャット本文を最大幅768px相当に制限し、中央寄せする。
- [ ] Markdownテーブルを必要時にテーブル領域内で横スクロールさせ、ページ全体の横はみ出しを防ぐ。

**検証:** 375pxと1280pxのビューポートで本文・入力領域・画面高を確認する。両幅でページ全体に横スクロールがないこと、1280pxでは本文幅が制限されること、375pxでは6列テーブルを領域内スクロールで閲覧できることを確認する。**必須:** スクリーンショット (Desktop 1280px / Mobile 375px) を取得し、画像でレビューすること。

## Phase 2: ナビゲーション

- [ ] デスクトップではサイドバーとチャット領域を併用できるようにする。
- [ ] モバイルでは限られた幅に適したサイドバー表示・開閉を整える（`ConversationList.tsx:72` の `w-64` 固定幅を画面幅に応じて調整する）。
- [ ] モバイルサイドバーを背景タップとEscapeキーの両方で閉じられるようにする。
- [ ] サイドバーの開閉状態がチャット本文・入力欄の利用を妨げないことを確認する。

**検証:** 375pxと1280pxでナビゲーション、本文、入力欄の重なりがないことを確認する。375pxではサイドバーを開き、背景タップとEscapeの両方で閉じられることを確認する。**必須:** スクリーンショット (Desktop 1280px / Mobile 375px) を取得し、画像でレビューすること。

## Phase 3: 入力

- [ ] 入力欄を各画面幅で見つけやすく、利用可能な位置に配置する。
- [ ] IME変換中判定 (`isComposing` または `keyCode === 229`) を共通処理にまとめる。
- [ ] チャット入力、設定内の全テキスト入力、および既存のConversationList入力で同じガードを使う。
- [ ] 変換中Enterでは送信・保存せず、変換確定後のEnterでは従来どおり送信・保存できるようにする。

**検証:** IMEガードの単体テストで `isComposing === true` のEnterが送信・保存を起こさないことを確認する。375pxと1280pxで入力欄の視認性・操作性を確認し、実機の日本語IMEで変換中と変換確定後のEnterをそれぞれ確認する。**必須:** スクリーンショット (Desktop 1280px / Mobile 375px) を取得し、画像でレビューすること。

## Phase 4: タッチ操作

- [ ] hover依存の削除・コピーなど主要操作をポインター端末向け表示に限定する。
- [ ] タッチ端末では対象操作を常時表示する。
- [ ] 各タッチ対象を44×44px以上とし、隣接操作を誤選択しにくくする。

**検証:** 375px相当の実機タッチ端末で主要操作がhoverなしで見つかり実行できること、各タップ領域が44×44px以上であることを確認する。1280pxではポインター端末での表示が既存と同じであることを確認する。**必須:** スクリーンショット (Desktop 1280px / Mobile 375px) を取得し、画像でレビューすること。

## 最終受け入れ確認

- [ ] 375pxと1280pxでナビゲーション・本文・入力欄が重ならず、ページ全体の横スクロールがない。
- [ ] 1280pxで本文の最大幅が制限され、375pxで6列テーブルを領域内スクロールできる。
- [ ] 実機スマートフォンで表示領域変化時も入力欄を含む画面を利用でき、`dvh` とsafe-areaが反映される。
- [ ] 実機タッチで主要操作を発見・実行でき、タップ領域が44×44px以上ある。
- [ ] IME単体テストと実機日本語IMEで変換中・確定後の挙動を確認する。
- [ ] モバイルサイドバーが背景タップとEscapeで閉じる。

**PASS条件:** スクリーンショット (Desktop 1280px / Mobile 375px) の取得と画像レビューが完了していない場合はPASSにしない。

**範囲外:** 機能追加およびデザイン刷新は行わず、`ui-spec.md` に列挙されたレスポンシブ対応に限定する。
